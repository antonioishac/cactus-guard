# Spec 035 — Identidade Visual e Logo (CactusGuard)

## Logo oficial do MVP

Logo aprovado: três formas arredondadas (estilo bumerangue) interligadas nas cores:

- Verde escuro (emerald)
- Preto / charcoal
- Dourado metálico

Texto: **Cactus** em charcoal + **Guard** em dourado, fonte moderna sans-serif.

## Uso

- Logo horizontal (símbolo + texto) como padrão em headers e documentos.
- Símbolo isolado para favicon, ícone de app e espaços reduzidos.
- Fundo branco ou claro.
- Não alterar proporções nem cores sem aprovação.

## Aplicação no Frontend

### Web (React)
- Header principal
- Tela de login
- Favicon
- Loading states

### Mobile (Flutter)
- Splash screen
- Header
- Ícone do app

## Arquivos
O logo final aprovado deve ser versionado no repositório de frontend em:
- `assets/logo/cactusguard-logo.svg` (preferencial)
- `assets/logo/cactusguard-logo.png` (fallback)

## Observação
Este é o logo oficial do MVP CactusGuard. Qualquer variação deve manter as cores e a composição das três formas.
