# CactusGuard Mobile

App Flutter do CactusGuard (PLD/FT) para analistas e supervisores de compliance.

- Rodar sem servidor: `flutter run --dart-define=USE_MOCK=true`
- Verificar: `flutter analyze` e `flutter test`

Arquitetura, configuração, segurança e passo a passo do FCM: ver [CLAUDE.md](CLAUDE.md).
